# 工作台：输入与伴随字幕

添加音频或扫描目录时，工作台自动发现同目录及 `ASMR_O` 子目录中的同名 VTT、SRT、LRC。支持 `Track1.vtt` 和 `Track1.mp3.vtt`，扩展名不区分大小写；多个候选均展示。

文件队列展示检测到的字幕语言，并随当前原语言、目标语言设置说明用途：

- 与原语言一致：可作为原文候选，执行时还会检查时间轴是否在音频范围内。有效时复用字幕，省去本次 ASR 推理。
- 与目标语言一致、与原语言不同：提示可能是译文，继续 ASR 获取原文。不会把译文当成录音原文，也不会用它覆盖字幕对齐输入。
- 多语言、语言不确定、无法读取或时间轴无效：不自动复用，保留 ASR。

语言判断是保守的文本字符检查，不是对音频内容的语义核验；原语言需由用户正确设置。双语行及仅夹杂少量假名的中文字幕不会自动按日语复用。是否内容准确仍需试听。

当前复用发生在已启用的 ASR 阶段，任务预检仍要求所选 ASR 引擎可用，便于字幕不能通过运行时校验时回退识别。暂不提供只凭字幕而跳过模型就绪检查的模式。目标语言译文仅展示，不自动替换翻译阶段。

重新扫描可刷新原有队列的字幕发现结果。执行结果中的 `companion_subtitle` 记录检测结果和未采用原因；原字幕文件保持不变。

带伴随字幕的旧阶段检查点会因字幕检查策略升级而失效，避免恢复过去未经语言检查的对齐结果；无伴随字幕任务的历史恢复指纹保持不变。已有正式语音检查点失效时仍沿用现有保护机制，要求另建任务，避免恢复时自动重复生成或计费。
