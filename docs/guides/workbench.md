# 工作台：素材、步骤与产出

工作台使用一组明确选择的素材执行一个任务。添加音频或 SRT/VTT 字幕，也可以扫描目录，再勾选本次需要的素材。同名伴随字幕作为候选展示；候选不等于绑定，多个文件不会自动选择。目录中的多个音频现在作为素材池，工作台不再隐式逐文件提交批次。历史批次与已有批次 API 保留。

顶部七个步骤的勾选是本次执行的唯一控制。程序不因语言相同自动勾选配音，也不因缺依赖自动补回识别、翻译或完整流程。初始流程为空，由用户选择。下方只配置已选步骤的素材来源和参数。

## 常用步骤预设

顶部“处理流程”里的流程预设与“设置 → 流程预设”读取同一份目录。先选择并查看步骤和产出，再点击应用。内置常用组合包括：

| 预设 | 勾选步骤 | 交付产出 |
| --- | --- | --- |
| 音频转字幕 | 语音识别 → 字幕导出 | 字幕文件 |
| 字幕翻译 | 字幕翻译 → 字幕导出 | 字幕文件 |
| 目标字幕直接配音 | 语音合成 | 配音音频 |
| 音频翻译配音 | 语音识别 → 字幕翻译 → 语音合成 → 字幕导出 | 配音音频、字幕文件 |

流程预设只填充明确列出的步骤与产出，不自动开始任务，不选择或替换素材来源，也不改变语种、声音参数、音量及字幕格式。背景混音或人声分离需要自行勾选。手动改变步骤或产出后按当前组合重新匹配，无匹配时显示自定义；匹配不表示素材或环境已就绪。

设置中的内置项只读，可以复制为自定义预设并编辑名称、说明、步骤与产出。保存后工作台从同一目录加载；同时编辑导致修订冲突时保留当前草稿并提示重新加载。旧内置条目继续保留，自定义项不改写安装目录的内置文件。

应用后，在“步骤输入”中确认各来源：例如识别绑定音频、字幕导出绑定识别产物；翻译后的配音绑定翻译产物。原绑定即使指向已取消的前序也会保留，并提示缺失，由用户决定如何调整。目标字幕直接配音仍要求目标语言证据和有效时间轴，异语或缺项不会自动补选识别、翻译等步骤。

应用流程预设时，产出以预览中明确列出的内容为准；重复应用同一预设保持同一组合。之后手动勾选步骤仍沿用既有默认产出规则，可自由调整。请在“产出”区确认实际交付内容；检查通过后再点击“创建并执行”。

TTS 高级预设与流程预设作用不同：在配音参数区先选择兼容引擎/模型，预览后应用满意试听保存的声音配置。它不改变素材、目标语言、步骤和产出，也不启动任务；具体保存方式见[声音与音色指南](voice-lab-v2.md#试音记录与正式任务)。

## 选择素材来源

每个已选步骤需要明确绑定素材或前序产物：

- 人声分离：选择音频，当前分离器产出人声音轨。
- 语音识别：选择音频，或已勾选分离步骤的人声音轨。勾选识别表示实际识别，不被未绑定的同名字幕替代。
- 时间轴校准：选择音频，以及字幕或识别产物。
- 字幕翻译：选择与源语言一致的字幕、识别或校准产物。
- 语音合成：选择与目标语言一致的字幕，或对应前序产物。异语字幕不能直接冒充目标文本；用户可自行选翻译并绑定其产物。
- 混音：选择底轨音频与叠加音频。底轨可用原音频或已选分离人声；叠加音频可用已有音频或合成产物。当前没有额外的背景轨提取能力。
- 字幕导出：选择字幕、识别、校准或翻译产物，使用现有 SRT/VTT 导出能力。

前序产物尚未生成也可满足计划依赖，状态显示“使用前序产物”。取消前序或移除素材后保留来源绑定并提示缺项，让用户自行调整；不会悄悄替换来源。后序引用、循环、类型矛盾、未选中的素材和缺少的阶段都会阻止提交。

输入字幕必须有完整非空文本和明确有效的起止时间。语言不确定时，由用户核对并明确确认语言；已检测为异语的字幕不能用语言确认改称目标语言。字幕与音频共同参与校准或混音时，须确认对应同一录音；后端还核验字幕时间轴不超出音频范围。这些检查不能证明字幕覆盖了录音中的全部话语。

## 选择产出与执行

“产出”区明确选择需要交付的文件，至少一项。勾选步骤时会列出该步骤的默认产出，可取消交付、仅供下游使用。识别步骤交付识别文本，翻译步骤交付翻译文本；要获得带时间轴的字幕文件，请勾选字幕导出并指定来源。分离、配音、混音交付各自音频。中间文件仍可为恢复保存在任务目录，但不会冒充用户选定的交付结果。

例如：

- 仅转换字幕：选择字幕，勾选导出并绑定该字幕；不要求音频、ASR、LLM 或 TTS。
- 已有目标字幕配音：只勾选语音合成并绑定字幕；不要求分离、ASR、对齐或翻译。需要字幕文件时再勾选导出。
- 异语字幕配音：勾选翻译和语音合成，翻译绑定字幕，合成绑定翻译产物。
- 从录音生成字幕：勾选识别和导出，识别绑定音频，导出绑定识别产物；不要求配音。

只检查已选步骤的模型、连接和能力。任何已选步骤失败都会停止，不换输入或补跑其他阶段。顶部区分“可选”“缺素材／确认”“使用前序产物”“执行中”“已完成”；素材检查通过不代表执行完成。

流程、素材选择、参数及产出选择保存在本机工作台草稿，恢复后重新校验文件与依赖。旧的底部复用／直达模式控制不再决定新任务；历史任务保留其提交快照，旧任务兼容逻辑只处理旧请求。素材提交后记录文件指纹，排队期间被修改则要求检查后重新提交，避免自动重复合成。

## 模型可用性缓存

运行环境的依赖导入与 CUDA 检查结果保存到项目 `.cache/runtime-probes/`，成功结果跨启动复用，不再每五分钟或每次启动自动重新导入依赖。文件存在性等轻量检查仍执行。缓存不包含凭据，也不表示模型已完成真实推理。

成功、明确缺少依赖和未能确认的结果分别保存。FunASR / Qwen3-ASR 的模块导入使用 45 秒总上限，其他环境模块及 CUDA 检查仍为 30 秒；不按模块数量无限延长。超时保持“状态未知”，显示当前模块和耗时，真实导入异常明确显示异常类型。ASR 未确认结果最多缓存 5 分钟，到期后下次查询重试；提示会明确标为历史缓存及上次检测时间，也可点击“验证”立即重试。旧版 ASR 失败缓存重新核验一次，旧成功缓存仍可复用；不会把超时当作缺依赖或可用。这些检查仅导入依赖，不代表实际 ASR 推理通过。

安装或修复依赖完成、点击模型“验证”会清除对应环境缓存；解释器、依赖目录/安装元数据、主要环境变量及 CUDA 驱动文件变化会使缓存失效。同一进程内并发请求同一环境共享检测结果。普通页面刷新复用仍有效的缓存。手工修改深层依赖文件或硬件状态变化未被文件签名识别时，请点击“验证”强制重新检查。

缓存损坏时重新检测；无法写入缓存时继续本次检测并保留进程内结果。缓存可删除后重建，不影响模型、配置、素材与历史任务。

重新扫描可刷新原有队列的字幕发现结果。执行结果中的 `companion_subtitle` 记录检测结果和未采用原因；原字幕文件保持不变。

带伴随字幕的旧阶段检查点会因字幕检查策略升级而失效，避免恢复过去未经语言检查的对齐结果；无伴随字幕任务的历史恢复指纹保持不变。已有正式语音检查点失效时仍沿用现有保护机制，要求另建任务，避免恢复时自动重复生成或计费。
