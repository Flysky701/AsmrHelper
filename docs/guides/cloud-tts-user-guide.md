# 云端 TTS 操作速查

## 1. 保存服务

在 **引擎与资源 → 外部服务 → 外部语音合成** 点 **添加服务**：

| 接口协议 | 默认 API 地址 |
| --- | --- |
| Fish Audio | `https://api.fish.audio/v1` |
| Gemini TTS | `https://generativelanguage.googleapis.com/v1beta` |
| ElevenLabs | `https://api.elevenlabs.io` |
| MiMo TTS | `https://api.xiaomimimo.com/v1` |

填写 **连接名称、API 密钥**，地址保持预填值；有“运行位置”时保持 **云端**。点 **保存服务**。模型和声音在下一步选择。

## 2. 保存音色

在 **声音与音色 → 音色预设** 点 **制作新音色**：

1. 填 **音色名称**，中文配音将 **合成目标语言** 选为 **中文**。
2. 按下表选 **引擎、声音来源、模型、声音**。
3. 在 **连接与参数** 选择刚保存的 **连接**；隐藏时展开 **高级连接设置**。点 **保存到音色库**，其余参数先用默认值。

| 引擎 | 声音来源 / 模型 | 声音怎么选 |
| --- | --- | --- |
| Fish Audio | **云端音色 ID**；可选 `s2.1-pro-free`、`s2.1-pro`、`s2-pro`、`s1` | 在 **当前使用的 Voice ID** 填已有 ID；也可用 **查找声音名称 / 声音范围** 查询，在 **可用声音** 选择后自动填入 ID。 |
| Gemini TTS | **内置声音**；先用 `gemini-3.8-flash-tts`，另有 `gemini-3.8-flash-lite-tts` | **内置说话人 ID** 保持 **Kore** 或选其他内置声音。 |
| ElevenLabs | **云端音色 ID**；可选 `eleven_v3`、`eleven_flash_v2_5`、`eleven_v4` | **服务端音色 ID** 填自己的真实 Voice ID，不填名称或网页链接。 |
| MiMo TTS | **内置声音**；`mimo-v2.5-tts` | **内置说话人 ID** 保持默认音色，或选“冰糖”等内置声音。 |

Fish 的“声音范围”包括 **我的公开音色（API 账号）**、**当前工作区音色**、**公共音色库（所有作者）**。查不到时可手填已有 ID；公共库不代表属于本人。这里选择已有声音，不执行克隆。

## 3. 输入短句试音

在 **试听与记录**：

1. **载入已保存预设** → 选择刚保存的音色。
2. 在 **试音原文** 输入一句台词，点 **生成试音**，完成后播放。
3. 需要微调时展开 **试听高级选项**，只改当前模型显示的参数，再生成比较。
4. 满意候选点 **另存为音色预设** → 填名称 → **保存所选结果的设置**。

音色编辑页也可直接用 **试听台词 → 生成试听**。保存候选设置后，下次可直接选择该音色。

## 4. 在工作台配音

1. **流水线预设** 选 **演示预设 · 中文配音**。
2. **调整参数 → 常用参数 → 语音合成 → 音色** 选自己的云端音色；出现确认时点 **确认更改**。核对下方引擎、模型及 **合成目标语言**。
3. **导入文件** 添加 SRT / VTT / LRC 字幕；展开素材组，绑定 **中文字幕**，核对并确认 **字幕实际语言**。
4. 勾选素材组，**输出位置** 留空用默认目录，点 **开始处理**。
5. **任务中心 → 对应任务 → 产物**：点 **播放**；用 **文件详情 / 复制路径** 找到文件。

想复用整条流程：参数面板 **另存为流水线** → 填 **新流水线名称** → **保存为新流水线**。

## 三个提示

- **普通文本走试音，工作台用时间轴字幕。** 中文演示原来使用 Edge，运行前要明确换成自己的云端音色。
- **检查配置只检查字段，不验证真实合成。** Voice ID、模型权限和费用以账户为准；模型名里的 `free` 不代表本指引保证免费。
- **超时先核对官网结果和计费，不连点重试。** 修改设置后从工作台提交新任务；旧任务的“重试”仍用原配置。

详细能力、参数及错误处理见 [统一 TTS 指南（含 Fish）](tts.md)、[三家云端扩展说明](../cloud-tts-extension.md)、[快速上手与常见失败](quick-start.md)。本速查不代表真实 API 测试已通过。
