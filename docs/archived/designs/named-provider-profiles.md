# 外部 LLM / TTS 命名连接配置

设置页按用途分别保存多份翻译连接与外部语音连接，用名称选择和调用。工作台可直接选择已保存的名称；编辑地址和密钥仍在设置页完成。

## 使用范围

- LLM 档案包含名称、提供商、基础地址、密钥和选定模型。模型选项来自所选连接的探测；手工输入仍作为明确的备用入口。
- TTS 档案使用 OpenAI 兼容接口，目前只显示名称、基础地址和密钥。已有模型、音色、接口格式和指令配置保留；新增档案不猜测这些能力。后续根据服务文档或探测结果补充。
- 空白密钥表示保留当前档案的密钥；新建档案从空密钥开始，不复制其他档案的凭据。接口响应仅返回是否已配置密钥。
- 旧 DeepSeek、OpenAI 和外部 TTS 配置自动映射为默认命名档案，首次修改时保存；原有内部调用继续使用兼容的配置结构。

## 任务隔离

任务创建时，在后端进程内保存当时的外部连接配置副本，执行和同进程重试使用该副本。之后切换档案、改名或修改地址与凭据，不影响已创建任务。密钥不写入公开 TaskSpec、任务响应或任务数据库。

本任务的连接副本仅在进程内保留。并行实现的任务三负责跨进程恢复契约：持久化非敏感连接信息及凭据版本引用，恢复时按原配置核验和解析，配置缺失或变化时阻止误调用，不能直接把密钥塞入执行清单。该部分的最终行为以任务三实现与测试为准。

## 验证原则

使用模拟连接测试档案隔离、迁移、候选模型探测和任务快照；不调用收费模型，不下载模型。前端执行类型检查与生产构建。
