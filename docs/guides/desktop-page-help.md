# 桌面页面操作说明

各节对应当前页面或子页；任务只在明确提交后执行。

## 外部服务

本节对应 **外部服务**，按当前页面显示的可用操作执行。

- **添加服务连接**：按用途选择外部语言模型或语音合成区域，新增相应服务。
- **填写连接信息**：填写名称、协议、地址和密钥；语音模型与声音在音色页选择。
- **保存并检查**：保存连接。检查配置只校验字段；模型查询与连接测试可能访问服务。
- **在对应模块使用**：翻译等节点选择语言模型连接；音色预设选择语音连接后保存。

### 使用提示

打开帮助、切换详情和复制公开示例不会提交处理任务。

云端语音服务的地址、模型与声音选择见 [云端 TTS 操作速查](cloud-tts-user-guide.md)。

## 音色预设

本节对应 **音色预设**，按当前页面显示的可用操作执行。

- **制作新音色**：填写名称与合成目标语言，选择引擎、模型和声音来源。
- **准备声音来源**：按所选方式填写声音 ID、描述或参考素材；只填写该引擎支持的字段。
- **配置连接与参数**：选择已保存的外部连接或本机设置，需要时展开高级连接设置。
- **保存并复用**：保存到音色库，之后可在试听页载入，或在工作台语音合成节点选择。

### 使用提示

打开帮助、切换详情和复制公开示例不会提交处理任务。

云端语音服务的地址、模型与声音选择见 [云端 TTS 操作速查](cloud-tts-user-guide.md)。

## 试听与记录

本节对应 **试听与记录**，按当前页面显示的可用操作执行。

- **载入已保存预设**：选择要试听的音色，核对引擎、模型和目标语言。
- **输入短句试音**：填写试音原文，明确点击生成试音后等待结果。
- **播放并微调**：播放候选；高级选项中每次只改一个参数，再生成比较。
- **保存候选设置**：满意候选点另存为音色预设，命名后保存所选结果的设置。

## 任务记录

本节对应 **任务记录**，按当前页面显示的可用操作执行。

- **筛选任务**：按分类、状态或名称定位任务，选择一项打开详情。
- **查看进度与错误**：查看阶段、日志和失败原因；刷新任务状态只更新记录。
- **检查运行产物**：在详情的产物中播放或查看文件，并复制路径定位结果。
- **按需处理记录**：取消和重试需明确操作；重试沿用原任务快照，删除前查看确认范围。

## 台本转字幕：整理台词

- **准备台本**：选择 PDF 或 UTF-8 TXT；整理台词不需要录音。
- **预览并确认**：预览台词和排除的动作说明，修订每行台词后确认；章节选项来自台本。
- **保存台词文本**：提交后输出 TXT，不生成字幕时间轴。LLM 清洗默认关闭，启用会发送文本。

## 台本转字幕：录音匹配

- **准备台本与录音**：选择对应录音、原文台本和录音语言；ASR 使用已安装的本地模型。
- **预览并确认**：预览、修订台词与动作说明，再确认台词和录音一致；可选择台本章节。
- **匹配并核对**：提交后在本页查看匹配、未匹配、额外录音和冲突；时间来自识别片段，不是逐字强制对齐。
- **试听修正再导出**：载入编辑器试听，修改时间或手动插入台词；待核对稿确认后导出，重试保留旧结果。

## 台本转字幕：复用原文字幕

- **准备原文字幕与录音**：选择台本、对应录音和原文 SRT/VTT，确认字幕为该录音的同语言原文，不能使用译文。
- **预览并确认**：预览、修订确认台词；参考字幕提供真实片段锚点并跳过 ASR。
- **核对后导出**：在本页核对匹配结果，载入编辑器试听修正；未匹配台词没有时间，不自动插入。
