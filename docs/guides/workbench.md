# 工作台：选择流水线、管理素材、提交处理

**选择流程**：选择已保存的流水线，先使用默认参数。

**准备素材**：导入文件或扫描目录，展开素材组并绑定必需输入。

**按需调整**：打开“调整参数”，只修改需要的模块设置。

**开始处理**：勾选素材组，明确提交。

**查看结果**：任务中心显示进度、错误与产物。

## 选择流水线

| 模板 | 用途 | 主要输入 |
| --- | --- | --- |
| 演示预设 · 中文配音 | Edge 中文配音，需联网 | 中文字幕 |
| ASMR正常流程 | 分离、识别、校准、翻译、合成和混音 | 按流程绑定音频与字幕 |
| TTS配音 | 配音与混音 | 目标字幕和原音频 |

需要改变节点、连线或输入槽时，进入“流水线编辑”；内置模板保存为副本。流程配置详见[流水线指南](workflow-graph-v2.md)。

## 导入素材

- 每个素材组只绑定本流程需要的输入。多个候选时手动选择，不按文件名自动认定录音相同。
- 核对字幕实际语言；用于校准或混音的字幕与音频应对应同一录音。缺项的组补齐输入，或取消勾选后再运行。
- 直接配音需要有效时间轴字幕。异语字幕选择含翻译节点的流程；字幕编辑可在“字幕工坊”完成。
- 删除素材组只移除工作台条目，磁盘文件、历史任务和结果保留。

## 调整参数

默认值适合先运行。“常用参数”设置各节点的引擎、语言、连接与音色；“高级参数”只显示该模块支持的选项。

关闭面板保留本次修改；要重复使用，点“另存为流水线”。素材绑定与输出位置不写入模板。识别模型及运行状态详见[模型检查说明](model-readiness.md)，声音配置见[声音与音色指南](voice-lab-v2.md)。

## 提交与结果

“输出位置”留空使用默认目录。所有勾选组校验通过后创建批次；缺输入或连接时按提示补齐。

任务中心显示阶段、错误和产物，可播放音频或复制文件路径。某组失败不会删除其他组的成功结果。

工作台重新提交使用当前配置；任务中心“重试”使用原任务配置，并从头处理该组。取消需要等待执行响应；云端结果未知时先核对服务端结果。

第一份演示输入见[快速上手](quick-start.md)。
