# 独立字幕对齐阶段

工作台的“校准字幕时间轴”默认关闭。开启后，流水线在 ASR 后、翻译前使用原音频校准源文字；其余阶段读取校准后的时间轴。对齐失败终止任务，不把原有时间轴冒充对齐结果。

StageProfile V1 增加可选 `stages.align`，provider 为 `qwen3_forced_aligner`，model 为 `qwen3-forced-aligner-0.6b`。旧配置缺省关闭。运行前通过现有模型管理检查模型与依赖；执行时独立 `qwen_asr` worker 仅加载 `Qwen3ForcedAligner`。不自动下载模型。

输入支持识别后的带时间轴文字、配套字幕，以及不超过 5 分钟音频的准确纯文字台本。长音频逐段使用已有时间锚点，两侧各留 0.75 秒余量，读取音频切片并按实际采样起点补全局偏移。单段不得超过官方 5 分钟限制。无时间锚点的长台本明确拒绝；本轮不实现长台本与粗识别的语义匹配，不按字数比例猜测时间。

模型返回时间单位按安装包官方 API 的秒处理，不通过整数/数值大小猜单位。拒绝非有限、倒序和超出片段范围的时间戳；零时长与段间重叠保留警告。原文保持不变，不声称模型提供置信度。

每次产生 `alignment_original.json`、`alignment_result.json`（segments / words / warnings，秒单位）及 `aligned.vtt`。源字幕不覆盖。恢复集成按整个 align 阶段保存和校验产物。

验证采用注入模拟模型及临时音频，覆盖切片偏移、秒单位、输入/输出时间校验、缺失模型、请求默认值、隔离 worker、阶段顺序和失败阻断。尚未进行真实模型推理与字幕质量验收。

当前 Qwen ASR 仍保留其内部时间戳生成以提供长音频锚点；再开启独立校准会有额外计算。复用其逐字结果需后续扩展 ASR 产物契约，不能仅按提供方名称认定已经完成独立校准。
