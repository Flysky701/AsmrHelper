说明

翻译功能调用 LLM 服务对字幕文件进行逐条翻译，支持输出双语格式。

工作流程：

  1. 选择要翻译的字幕文件
  2. 配置翻译服务和语言方向
  3. 点击"开始翻译"提交后台任务
  4. 在任务中心查看翻译进度
  5. 完成后可在编辑器中打开结果

注意事项：

  • 翻译通过 LLM API 执行，需要配置有效的 API Key
  • 大文件翻译可能需要较长时间
  • 双语模式会在每条原文下方添加译文

模式说明

纯文本模式 — 从台本提取文本，LLM 清洗后直接生成字幕。不含精确时间轴。

音频对齐模式 — ASR 识别音频 → 与台本对齐 → 生成带时间轴的字幕。精度最高。

VTT 重对齐模式 — 已有 VTT 文件 + 台本，重新清洗和对齐。适合修正错误。
