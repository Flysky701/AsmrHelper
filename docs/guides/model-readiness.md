# 模型检查说明

## 模型可用性缓存

运行环境的依赖导入与 CUDA 检查结果保存到项目 `.cache/runtime-probes/`，成功结果跨启动复用，不再每五分钟或每次启动自动重新导入依赖。文件存在性等轻量检查仍执行。缓存不包含凭据，也不表示模型已完成真实推理。

成功、明确缺少依赖和未能确认的结果分别保存。FunASR / Qwen3-ASR 的模块导入使用 45 秒总上限，其他环境模块及 CUDA 检查仍为 30 秒；不按模块数量无限延长。超时保持“状态未知”，显示当前模块和耗时，真实导入异常明确显示异常类型。ASR 未确认结果最多缓存 5 分钟，到期后下次查询重试；提示会明确标为历史缓存及上次检测时间，也可点击“验证”立即重试。旧版 ASR 失败缓存重新核验一次，旧成功缓存仍可复用；不会把超时当作缺依赖或可用。这些检查仅导入依赖，不代表实际 ASR 推理通过。

安装或修复依赖完成、点击模型“验证”会清除对应环境缓存；解释器、依赖目录/安装元数据、主要环境变量及 CUDA 驱动文件变化会使缓存失效。同一进程内并发请求同一环境共享检测结果。普通页面刷新复用仍有效的缓存。手工修改深层依赖文件或硬件状态变化未被文件签名识别时，请点击“验证”强制重新检查。

缓存损坏时重新检测；无法写入缓存时继续本次检测并保留进程内结果。缓存可删除后重建，不影响模型、配置、素材与历史任务。

重新扫描可刷新队列的字幕发现结果，原字幕文件保持不变。V1 检查点是否可复用仍须核验原素材、字幕策略与语音快照，失效时明确要求重新提交，不自动重复生成或计费。

## ASR 参数

图节点中 ASR 未显式设置的动态设备/精度显示为引擎自动值，不把展示建议当成执行值。Qwen 时间戳的有效行为同时受强制对齐器影响。`hotwords`、`vad_kwargs`、`forced_aligner_kwargs` 等能力声明中的数组/对象不是无效旧参数；编辑校验与保存往返保留它们，不能因为标量控件无法展示而删除。
