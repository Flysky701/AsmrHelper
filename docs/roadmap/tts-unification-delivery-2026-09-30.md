## 必要兼容边界

- `TtsEngineService` 是 CLI/旧 DTO 的薄转换入口，不再拥有引擎注册表或独立执行器。无法确定的旧音色档案和冲突参数明确拒绝，不静默忽略。
- `/capabilities` 的 TTS 部分仅是新目录的格式转换。
- 旧配置导入只新增连接，不设默认、不猜测规则；无法可靠转换项保留。导入使用独立文件锁串行化，账本避免重复导入覆盖。
- 新任务连接恢复记录为版本 2，仅捕获 LLM 配置；旧版本 1 的连接恢复记录继续支持读取。Speech 的凭据通过固定引用解析。
- 历史任务和用户素材没有批量迁移、删除或覆盖。对旧检查点序列化的兼容必须先验证完整语音身份与产物，不能据旧默认值重新合成。

- 前端生产构建：TypeScript + Vite 通过；4 项 Node 行为测试通过，覆盖直接 Speech 配置、深复制、缺失配置拦截、关闭配音与脱敏导入请求。
- 静态检查：Ruff `F821/F601/F401` 全项目源码、脚本及测试通过。
- 离线端到端：真实 CLI、快照、编译器、存储和组装，模拟 Provider 生成真实可解码 WAV；包含 Fish 命名连接、保存规则、参数冲突、产物归属及 Worker 异常清理。
- 真实远端合成：Edge 中文短句经统一服务完成，输出 98,432 帧、44,100 Hz、2.232 秒；在隔离临时目录执行，没有使用或修改用户语音连接，验证后临时文件清理。
- 本机旧配置脱敏盘点：可直接导入 0 条、需保留 1 条、已导入 0 条；旧本地 TTS 设置存在并保留。本轮没有执行有损转换或修改用户配置。

## 未验证与保留项

- 本轮没有调用 Fish、MiMo 或 OpenAI 兼容的真实付费服务；相关验证使用模拟响应，不作为账号权限或音质验收。
- 本轮没有重新运行 Qwen3、VoxCPM2 的真实模型；现行隔离 Worker 的调用参数和音频出口已离线验证。
- 未进行桌面人工点击验收。前端构建及行为测试不替代完整交互验收。
- 无法可靠映射的旧模型、音色、指令、本地设置仍保留在原配置。后续按实际服务能力补齐新配置，不能当作已成功转换。
- 本地 `audit/` 审查材料继续保留，不纳入产品提交。
