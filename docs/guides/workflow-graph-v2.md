# 节点工作流 V2：接口与预览边界

源码现已接入工作台和独立流水线编辑页。工作台选择已保存的流水线、管理素材并调整本次参数；编辑页负责节点、连线、素材槽和产出，历史与结果在任务中心查看。运行版以每次发行核验的 exe 哈希及后端能力为准，不从源码提交推断；本轮素材目录与设置修改尚未刷新运行版。没有自动迁移旧版步骤草稿；源码通过 mock 不代表真实模型与桌面交互已验收。

## 一个图决定执行内容

`execution_profile.version = 2` 时只接收 `graph` 与 `bindings`。图定义包含 `version: 2`、`nodes`、`edges`、`input_slots`、`outputs`；不再同时接收全局步骤开关作为第二个执行依据。同一能力可以有多个唯一节点实例，按拓扑顺序串行执行，每个实例写入自己的 `nodes/node-<id>` 目录。节点 ID 大小写也必须唯一，防止 Windows 目录碰撞。

| 能力 | 输入 | 输出 | 当前限制 |
| --- | --- | --- | --- |
| separate | audio | audio | 现有 Demucs 人声轨；没有伪造背景轨端口 |
| asr | audio | subtitle | 使用该节点所选 ASR |
| align | audio + subtitle | subtitle | 要确认同一录音和时间轴 |
| translate | subtitle | subtitle | 节点明确源/目标语言及翻译连接 |
| tts | subtitle | audio | 字幕必须匹配目标语言，声音快照按节点冻结 |
| mix | audio + speech（两者均 Audio） | audio | 确认共同时间轴；用户选择跟随主轨或保留完整长度 |
| export | subtitle | subtitle | 复用 SRT / VTT / LRC 导出 |

图允许分支、合流、重复能力，不允许循环或给一个输入端口绑定多个来源。缺少输入、类型或语言矛盾直接报错；不自动补节点、不回退全流程。只检查图内节点使用的引擎和连接。未使用的素材槽可以暂时不绑定。

素材槽声明类型，运行时的 `bindings` 才包含具体路径。语言未知的字幕需要确认；字幕与音频一起使用需明确对应，检查时间轴。提交时冻结素材身份，执行前重新核验，素材变化会要求重新提交。只有目标字幕和一个 TTS 节点时，不执行或预检分离、ASR、翻译。

## 模板和现有任务

`GET /api/v1/pipeline/graph-capabilities` 返回七项能力及串行执行/不支持部分续跑说明，不初始化模型。V2 模板复用现有 `PresetCatalogService` 和 `/api/v1/pipeline/presets`；通过 `include_graph=true` 获取同目录的 V1/V2 条目。旧客户端默认只看到 V1。创建、复制、修订冲突与内置只读规则沿用原服务。

模板保存图、节点参数、素材槽和明确产出，不保存具体素材绑定、凭据、运行快照或画布坐标。连接使用引用，翻译凭据仅保留在任务服务私有内存；声音使用已有不可变配方快照。正式编辑页使用同一目录的创建、复制及修订接口，保存后可以回到工作台选中该流水线。

编辑页顶部提供保存、另存与返回。名称为空或结构缺少输入/产出时会说明不能保存的原因；后端保存失败、修订冲突或取消离开均保留当前草稿。内置定义编辑后使用“保存副本并返回”，自定义预设可以更新或另存。每个条目只显示一个“删除”入口：内置仅删除活动索引并可恢复；自定义删除完整定义，须确认且不可从产品内恢复。

内置“删除”调用 `DELETE /api/v1/pipeline/presets/{id}?revision=N`，只删除活动索引；自定义使用原永久删除接口。成功返回 204，修订/状态冲突 409、条目不存在 404。`GET /api/v1/pipeline/presets/archived?include_graph=true` 返回可恢复条目；通过恢复入口填写名称，调用 `POST /api/v1/pipeline/presets/{id}/restore`（`revision`、可选 `label`）显式恢复同一 ID。活动目录中已有同名条目时返回 409，要求改名，不覆盖用户条目。恢复只更新目录，不替用户选中或覆盖打开的编辑草稿；旧版已归档自定义仍保留单独恢复入口，不因本轮界面简化丢失。

删除索引不影响已提交任务的快照或结果；编辑草稿、工作台运行参数与素材绑定保留。目录重载发现旧选择已移除时解除预设 ID，并明确显示保留的未保存草稿；用户可另存、新建或恢复。空目录不创建替补样例、不选取不可用的旧 ID。目录核对与保存互斥，避免旧选择校正导致服务端已另存、页面却没有成功反馈。

删除节点与删除预设是两种操作。在右侧节点设置标题中使用“移除此节点”，会同时移除该节点的关联连线和声明产出；下游缺少来源时明确提示，不自动补节点或改线。模块库和参数区各自滚动；画布可横纵滚动，并可用“定位节点”访问边缘节点。

`config/presets.yaml` 仅保留用户指定的“ASMR正常流程”（`custom_07458dd97f9e467eb6aef34d499923a5`，r2）和“TTS配音”（`custom_964998d159ec4c30a5cc6bf44b76caeb`，r1），完整节点、连线、参数和最终产出保持原配置。原六个 V1、四个 V2 内置定义已移除，不再出现在恢复列表；历史任务快照不变。其他自定义仍由用户文件提供，不按名称推断或批量清除。

旧用户文件中同 ID、同修订且配置匹配的两条自定义，在读取视图中标记为内置，不改写原文件；仅允许 API 已添加的可选 `null` 字段差异。内容或修订已被用户改动时返回冲突并保留全部数据。旧十条索引仅作格式兼容，不再有对应定义；未知索引 ID 仍报错。后续显式保存保留这些原始记录，写前按哈希备份，不借其他操作清理待确认数据。目录同步只更新打开草稿的来源标志，保留其图和修订；不能据新内置目录覆盖未保存编辑。

同一个 `config/voice_lab/flow_presets.json` 的 V3 格式保留完整自定义定义和活动索引、修订、恢复显示名称，没有第二套预设存储。读取旧 V1/V2 文件只计算目录，不写盘；首次实际保存/移出/恢复前，将旧文件逐字节备份为同目录 `flow_presets.json.pre-v3.<SHA256>.bak`，验证后原子替换。损坏目录、备份失败、修订冲突或外部并发变更均阻止覆盖。回退旧程序前须保护当前 V3 文件，再在停用实例时按需要恢复旧版备份；不要让旧程序覆盖新索引。声音、TTS 高级预设、连接、素材和任务存储均不在迁移范围。

设置页的“预设管理”和工作台使用同一目录；复制、恢复、删除不会自动选用或提交任务。“文件与缓存”仅提供现有的输出、字幕、模型缓存和临时目录四项设置，校验后仅提交实际修改项，不移动已有文件。加载失败或保存失败保留用户输入。

`POST /api/v1/pipeline-runs` 接受 V1 或 V2，V2 仍沿用原任务队列、状态与产物索引。返回产物保留 `node_id` / `port`，不会按能力名称覆盖同类型实例。旧 V1 默认版本、显式 `model: null`、历史读取和阶段恢复继续保留。

V2 暂不支持节点级缓存、部分续跑、失效传播或自动重跑。重启后中断的图任务保留历史，并明确不能续跑；显式重试会重新执行整个图。结果未知的远程请求仍需按原规则核对，不自动重试。

## 明确分组的图批次

`POST /api/v1/batch-runs` 的 V2 请求使用共同的 `execution_profile: {version: 2, graph}` 和 `groups: [{group_id, label, bindings}]`，不混用 V1 的 `inputs`。组 ID 唯一且稳定；相同主文件可以属于不同绑定组合，不按路径静默去重。V1 请求与历史记录仍保留原契约。

所有组的图、语言、对应关系和素材身份先通过校验，才创建持久化批次并启动既有监控器。共同声音及翻译配置在接纳时冻结，不提前注册一批可执行的 pending 任务来绕过批次并行限制。每组通过原任务服务创建普通 DAG 子任务，节点/任务输出目录和产物索引继续隔离。

`client_request_id` 标识一次提交；相同标识与相同请求返回已接纳批次，标识复用于不同内容会报错。它不表示自动重试执行。响应保留 `current_task_id`、历史 `task_ids` 和组内状态，并提供重试可用性/阻止原因。浏览器迟到响应不能替换后来的编辑草稿或把旧错误串入另一组。

失败重试复用冻结配置；已完成组不重复执行。输入身份改变、远端结果未知或没有原冻结上下文时要求用户重新核对，不能从最新设置恢复一个“相同”任务。普通任务接口不允许直接重试或续跑批次子任务，避免绕过组归属和批次并行限制。私有连接上下文只在进程内保留，不放进公开响应或批次持久化 JSON；重启后的历史图批次不宣称可以续跑。暂停、节点级续跑和缓存均不在本轮范围。

目录发现通过 `media_kind` 区分 `audio`、`subtitle`、`all`，默认保持旧音频发现行为。工作台可扫描字幕文件并形成字幕独立的组。文件名/相邻位置仅提供配对候选，不替代语言与时间轴确认。

## 参数展示与执行缺省

## 混音输出长度

混音节点的“输出长度”复用 `options.output_length`，可保存到预设并随运行和批次图冻结：

- **跟随主音轨（main，默认）**：输出跟随主音轨时长，配音超过主轨末尾的部分会截断。旧模板没有该字段时采用此默认值，打开页面不改写模板。
- **保留完整音轨（longest）**：输出到主轨结束与偏移后配音结束的较晚位置，没有音频的部分保持静音。

延迟为正时配音延后，负值时提前；零点之前的配音被裁掉。若配音整体提前到零点前，输出仍保留主音轨，配音贡献为静音。长度选择不会自动补充节点、改变素材或开始执行。无效长度值、无效音频及未确认素材对应关系仍报错。

长度策略不修改音量算法：原音音量为线性增益；TTS 比例以未经原音增益处理的主轨 RMS 为参考计算配音增益，之后仍使用 FFmpeg amix 原有默认归一化。没有新增自动闪避、LUFS 对齐或限幅器。采样率转换的取整会带来采样帧级差异，结果元数据记录真实产物时长及长度/延迟策略。
