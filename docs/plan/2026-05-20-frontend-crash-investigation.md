# 前端闪退排查与修复计划

## 目标

- 定位当前桌面前端闪退的真实原因。
- 修复导致 Tauri 桌面窗口无法稳定启动的问题。
- 验证开发模式、构建模式和启动脚本路径下的表现。

## 背景

- 当前前端构建已可通过，但用户反馈桌面端存在闪退问题。
- 闪退更可能发生在 Tauri 主进程启动阶段，而非纯前端构建阶段。

## 步骤

1. 直接运行 `npm run tauri dev`，抓取真实启动日志。
2. 修复 Tauri 配置或启动入口中的致命错误。
3. 重新验证 `tauri dev`、前端构建与 Rust 侧检查。
4. 记录修复结论与剩余风险。

## 验证

- `npm run tauri dev` 不再因配置错误立即退出。
- `npm run build` 仍可通过。
- `cargo check` 仍可通过。

## 风险

- 修复首个启动级 panic 后，可能还会暴露下一层运行时问题。
- 启动脚本依赖本地环境和后端服务状态，仍可能出现环境类问题。
