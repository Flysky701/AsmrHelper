# 快速上手：第一份中文配音

默认演示使用 Edge 在线晓晓音色：**不用下载模型，不用原音频，不用 API 密钥，但必须联网**。字幕文本会发送到 Edge 语音服务。免模型下载不等于离线可用；它适合先熟悉输入、提交和结果查看。

## 启动与工作区

- 安装版：从已安装的 ASMR Helper 快捷方式启动。首次弹出“选择工作目录”时，点击“选择目录”，选一个专用可写的空文件夹（或已有 ASMR Helper 工作目录），不选程序安装目录；再按提示准备基础运行环境。
- 源码版：先在项目目录执行 `powershell -ExecutionPolicy Bypass -File .\setup.ps1`，再双击 `RUNGUI.bat`。基础安装不必传 `-Models` 或 `-Full`；首次准备依赖和桌面构建仍需相应工具与网络，见[安装指南](installation.md)和[开发入口](development.md)。
- “设置 → 文件与缓存 → 工作目录”显示配置、任务及资源的保存位置。目录要有写入权限；“更改工作目录”下次启动生效，旧数据不会自动迁移。源码入口固定主项目工作区时会明确提示。

## 从字幕到音频

1. 打开“工作台”，选择 **演示预设 · 中文配音**。空白工作台会默认选中它；已有选择、参数或草稿保留，不自动执行。
2. 用项目自带的 [first-use.zh.srt](../examples/first-use.zh.srt)，或将以下内容保存为 UTF-8 的 `first-use.zh.srt`（注意不要保存成 `.srt.txt`）：

   ```srt
   1
   00:00:00,000 --> 00:00:08,000
   欢迎使用。放松下来，听一听这段中文配音。
   ```

3. 点击下方“导入文件”，选择字幕。点击素材组名称展开，检查“中文字幕”槽；如显示语言未知，选择“字幕实际语言 → 中文”，勾选“确认字幕实际语言”。无需配对音频。
4. 勾选该组，点击“开始处理”。“输出位置”留空使用工作区默认目录，通常为工作区下的 `output/`，结果按任务和素材分目录。
5. 点击“任务中心”，查看该批次中的任务、错误与音频产物，完成后试听并查看实际文件位置。素材就绪或依赖检查通过不代表合成成功。

只有普通文本时，可在“声音与音色 → 试听与记录”载入“Edge 中文·晓晓”，在“试音原文”输入中文，点击“生成试音”。无需先转为字幕；这一入口生成试音记录，工作台仍使用 SRT / VTT / LRC 时间轴字幕。删除过默认音色时可在“音色预设 → 默认音色”点击“添加 Edge 默认预设”。

## 再使用完整流程

“ASMR正常流程”仍保留分离、识别、校准、翻译和混音，需 Demucs、Whisper、Qwen 强制对齐器等模型、翻译连接及明确的 TTS 音色。“TTS配音”需要目标字幕与原音频，也需在“调整参数”选择具体声音来源或已保存音色。

在“引擎与资源”按需操作“安装/修复环境”“下载模型权重”，或在“使用已有模型”区块点击“引用此目录”。模型权重和运行环境是两项准备；Qwen、Fun-ASR、VoxCPM 等使用独立 `.runtimes/`，不要将互相冲突的依赖全部装进主 Python。在线翻译/语音服务的网络、凭据和计费要求取决于所选服务。演示不会自动选择这些服务。安装和就绪检查不能代替真实推理验证。

## 常见失败

- **要求模型或翻译密钥**：核对选中的是中文配音演示，且没有添加识别/翻译节点。原完整流程仍需其各项依赖。
- **无法开始处理**：展开素材组，补齐字幕槽、确认实际语言和勾选状态。空白字幕、结束早于开始或格式错误时先用“字幕工坊”修正；日语/英语字幕不能只勾选中文冒充翻译。
- **Edge 合成失败**：在任务中心看错误，检查能否访问 Edge 服务。网络不可达、超时或服务限制时稍后明确重试；不会自动下载本地模型或改用付费引擎。
- **缺少 Edge/FFmpeg 依赖或无法写输出**：源码版重新按安装指南准备基础依赖；安装版保留日志并检查安装是否完整。核对“工作目录”和“输出位置”的权限、可用空间，不要删除配置、模型或历史来修复。

删除演示预设后，重启不会自动添加。需要时在“设置 → 预设管理 → 添加内置模板”新建独立预设；现有自定义流程和草稿不会被演示覆盖。
