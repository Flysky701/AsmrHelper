# 声音库与音色生成规则

## 声音库

声音库用于准备人声克隆的参考录音。导入后可以查看波形、试听或循环选区，保留整段或裁出片段；音量调整与淡入淡出提供处理后试听，满意后另存。增益会导致削波时拒绝保存，不自动改变用户设置。

每段声音可填写名称、备注、语言及对应文本。未识别/未核对文本也能先存入声音库；克隆引擎需要确认文本时，必须补齐并确认才能保存对应音色规则。已有字幕仅辅助定位与填写，不自动当成已核对的转录。

原音频保留，裁剪与处理另存新片段并记录来源。归档只隐藏素材，不删除历史任务可能引用的文件。浏览器直接上传音频（单文件上限100 MB），桌面端也可使用本机文件选择。

## 我的音色

音色保存的是生成规则，不是训练出的独立模型，也不是某次试音的固定音频。新建规则提供两种创建方式：

- **参考克隆**：选择声音库片段及支持参考克隆的引擎。
- **描述创建**：输入声音描述，选择支持声音设计的引擎。

一个规则对应一个引擎、模型及连接，保存名称、备注、来源和实际有效参数。界面不提供普通、轻声、耳语标签或多引擎实现配置；内部兼容旧历史的字段不要求用户配置。支持方式、模型及参数均由引擎声明，不能保存不支持的组合。

保存不要求先试音。音色编辑产生新修订，工作台默认列出最新未归档规则；已经提交的任务仍使用原配置。旧内置音色/服务端音色配置继续可以读取与调用，不自动转换为新克隆规则。

## 试音记录与正式任务

短句试音用于验证生成规则，台词、候选音频及采用记录单独保存。规则相同不保证每次声音完全一致；不会自动把候选变成克隆参考。

正式配音仍由工作台 Pipeline 负责。选择音色后提交，按正式台词逐句合成、适配时间轴、混音和导出。试音/正式实验的候选采用及组装保留，不另建一套正式配音流程。

## 数据与历史

资料位于 `config/voice_lab/`，元数据在 `store.json`；凭据单独存于 `credentials/`，不要分享整个资料目录。来源音频、候选和组装保留；归档不进行物理删除。

旧 `/voice/*`、`/tts/*` HTTP 入口已退出运行链路。旧文件不删除、不自动导入；显式导入工具为 `scripts/import_voice_library.py --help`，执行导入前会备份。旧任务不因新规则编辑而改变原配置。
