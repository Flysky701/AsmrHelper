## Compatibility

`audio_difference` is a graph node with explicit reference and mixed inputs. It subtracts a fixed-offset, gain-adjusted reference and reports residual limitations; it is not general-purpose AI separation. `mix` supports 1–32 tracks while preserving legacy templates without `tracks`. Language and backgrounds remain local appearance preferences, outside the graph, execution request and preset schema. Dynamic values, user labels, file paths and port IDs remain verbatim.

The added integration regression tests exercise the real appearance store, i18n, workflow save API payload and JSON reload. They verify that language/overlay/background changes preserve audio options, dynamic connections and user text. The older appearance test loader now loads the audio dictionary.

## Synthetic execution

A new isolated preview backend executed a saved two-node graph against generated audio only. `pipeline-1` completed, automatically recovering a 90 ms reference offset and gains approximately 0.8 / 1.1. The difference artifact is 2.0 s at 16 kHz stereo. Three-track mixing with independent gains and offsets also accepts a 32 kHz mono source and produces 2.2 s at 16 kHz stereo. Both artifacts retain node identity and preview metadata.

## Follow-up: canvas zoom and pan

The existing DOM/SVG workflow canvas now has 25%–200% view zoom, minus/plus controls, a percentage indicator, fit-to-node-bounds (within the zoom limits), and reset to 100%. Alt + wheel zooms around the pointer inside the canvas. With the canvas region focused, +/− zoom, 0 resets, and F fits. Input editing, ordinary wheel scrolling, and browser Ctrl/Meta zoom gestures remain untouched.

Only the canvas display is scaled. Card positions, graph JSON, preset schemas and parameter-panel dimensions remain unchanged. Scaled pointer movement and measured SVG endpoints are converted back to unscaled canvas units; the scroll extent follows the scaled dimensions and node reveal uses scaled positions. No canvas library or new dependency was introduced.
