# 声音库与音色生成规则

本页只说明声音库、规则与试听交互。TTS 能力、连接、命令行、数据归属及旧配置迁移的唯一入口为 [统一 TTS 指南](tts.md)。

## 声音库

声音库用于准备人声克隆的参考录音。导入后可以查看波形、试听或循环选区，保留整段或裁出片段；音量调整与淡入淡出提供处理后试听，满意后另存。增益会导致削波时拒绝保存，不自动改变用户设置。

录音编辑使用同页工作台：选段、录音信息和音频处理同时可访问，没有必须依次完成的步骤。播放器默认播放框选范围，到终点停止或按“循环选段”返回起点；“试听整段”临时播放完整录音，修改选段后恢复选段播放。

辅助选段优先复用原音频同目录的 VTT/SRT（支持 `录音.vtt` 和 `录音.mp3.vtt` 等命名），检查时间范围与所选语言。录音语言未确定、字幕语言不一致、双语或无法可靠判断时不复用字幕，并显示原因；处理后的片段不套用原始长音频的时间轴。语言判断只是保守的文字检查，不等同于核验字幕与音频实际内容一致。浏览器上传无法直接读取本机同目录，可手动加载字幕；手动加载的字幕优先参与分析，也可直接选择字幕片段。

无可用字幕时，默认按停顿和音量变化寻找候选，不进行语义判断；勾选“无可用字幕时运行 ASR”才重新识别。分析显示当前阶段、阶段进度、已用时间、结果来源和失败原因；阶段百分比不是剩余时间估计。取消会在当前处理阶段结束后生效。分析期间仍可手动编辑，选用候选不会自动保存。

每段声音可填写名称、备注、语言及对应文本。未识别/未核对文本也能先存入声音库；克隆引擎需要确认文本时，必须补齐并确认才能保存对应音色规则。已有字幕仅辅助定位与填写，不自动当成已核对的转录。

录音信息中的“识别选段原文”独立运行 ASR：只识别框选音频，不读取任何附带字幕。识别有后台进度和取消入口，完成后填入待核对原文；如果期间改动了选段、语言或原文，结果不会自动覆盖当前编辑内容。该操作不自动保存录音，也不会自动勾选“原文已核对”。

原音频保留，裁剪与处理另存新片段并记录来源。归档只隐藏素材，不删除历史任务可能引用的文件。浏览器直接上传音频（单文件上限100 MB），桌面端也可使用本机文件选择。

## 我的音色

声音库与我的音色采用一致的列表和详情布局，窄内容区可展开列表切换。录音详情中“用此录音创建音色”建立独立草稿，不覆盖当前保存的音色；归档放在详情的“更多”菜单，历史素材和任务保留。

音色保存的是生成规则，不是训练出的独立模型，也不是某次试音的固定音频。新建规则按引擎提供实际支持的方式：

- **参考克隆**：选择声音库片段及支持参考克隆的引擎。
- **描述创建**：输入声音描述，选择支持声音设计的引擎。
- **内置、服务端或默认声音**：从引擎提供的真实声音来源中选择；服务端模式需要明确连接及音色 ID。

一个规则对应一个引擎、模型及连接，保存名称、备注、来源和实际有效参数。表单分基本信息、生成方式和运行设置，参考录音可就地预览。高级参数折叠显示，引擎支持时才提供发声、情绪或停顿选项；不支持的参数会说明原因，不静默忽略。历史多引擎声音保留兼容读取，不要求重新填写。

保存不要求先试音。音色编辑产生新修订，工作台默认列出最新未归档规则；已经提交的任务仍使用原配置。旧内置音色/服务端音色配置继续可以读取与调用，不自动转换为新克隆规则。

外部语音服务在“引擎与资源 → 外部服务”独立新增和编辑地址与凭据，不需要先创建音色。Fish Audio 预填官方基础地址并使用云端运行位置；其他兼容服务可指定运行位置。超时使用内部默认值，编辑既有连接时保留已保存值。音色规则只引用已保存的外部连接；本地模型连接仍在音色编辑中配置。“检查配置”仅校验配置完整性，不代表已经联网验证或合成成功。

## 试音记录与正式任务

短句试音用于验证生成规则，台词、候选音频及采用记录单独保存。规则相同不保证每次声音完全一致；不会自动把候选变成克隆参考。

1. 在“我的音色”选择引擎与声音来源，进入“试音记录”。未命名、未保存的草稿也可试听。
2. 展开“试听高级选项”，调整当前引擎声明的参数。Qwen Base 参考克隆本身就是 Zero-shot；启用“仅使用声音特征”可不提供原文，仍必须选择参考音频。关闭该选项时，原文必须已填写并核对。
3. 明确点击“生成试音”才创建合成任务。每次请求固定当时的配置；“检查请求”仅编译，不合成。
4. 满意后在对应候选上选择“保存为TTS高级预设”并命名。保存取该候选生成时的冻结快照和有效参数，后续表单修改不会混入，也不会覆盖当前草稿。
5. 在工作台选择兼容引擎和模型，预览 TTS 高级预设后明确应用。预设只改变声音来源与合成设置，保留素材、步骤、产出及目标语言。语言不兼容、旧修订、缺少连接或参考录音会提示，需明确纠正后使用。

TTS 高级预设就是现有音色规则的不可变修订，不是第二份设置目录。设备和模型路径留在连接中，凭据不进入预设。试听和正式任务共用参数验证与映射；正式任务可能按字幕时长处理音频，因此不保证与试听逐字节相同。

正式配音仍由工作台 Pipeline 负责。先选择引擎与模型，再选择它支持的声音来源；自定义规则是可选项，无需先到音色管理保存规则或试音。Edge 和 Qwen CustomVoice 提供引擎预设，VoxCPM2 提供文本直出的默认模式；参考克隆、声音设计和外部服务音色仍需相应录音、描述或音色 ID，不会虚构默认声音。实际可运行性由提交前的环境与配置检查确认。

规则列表只提供与当前引擎、模型兼容的未归档规则。直接引擎配置和已保存规则都在提交时固定为任务快照，按正式台词逐句合成、适配时间轴、混音和导出，共用现有合成执行能力。试音/正式实验的候选采用及组装保留，不另建一套正式配音流程。

## 数据与历史

正式配音仍归所属任务目录，独立试听和参考录音保留各自目录。完整目录约定、凭据保护、历史记录读取及旧连接显式导入见 [统一 TTS 指南](tts.md#数据归属与历史)。声音库导入工具 `scripts/import_voice_library.py --help` 仅用于旧声音资产，不是服务连接迁移工具。
