# 节点工作流 V2：接口与预览边界

源码现已接入工作台和独立流水线编辑页。工作台选择已保存的流水线、绑定素材并调整本次参数；编辑页负责节点、连线、素材槽和产出。没有自动迁移旧版步骤草稿、替换桌面发行文件或重启应用。源码通过 mock 不代表真实模型与桌面交互已验收。

## 一个图决定执行内容

`execution_profile.version = 2` 时只接收 `graph` 与 `bindings`。图定义包含 `version: 2`、`nodes`、`edges`、`input_slots`、`outputs`；不再同时接收全局步骤开关作为第二个执行依据。同一能力可以有多个唯一节点实例，按拓扑顺序串行执行，每个实例写入自己的 `nodes/node-<id>` 目录。节点 ID 大小写也必须唯一，防止 Windows 目录碰撞。

| 能力 | 输入 | 输出 | 当前限制 |
| --- | --- | --- | --- |
| separate | audio | audio | 现有 Demucs 人声轨；没有伪造背景轨端口 |
| asr | audio | subtitle | 使用该节点所选 ASR |
| align | audio + subtitle | subtitle | 要确认同一录音和时间轴 |
| translate | subtitle | subtitle | 节点明确源/目标语言及翻译连接 |
| tts | subtitle | audio | 字幕必须匹配目标语言，声音快照按节点冻结 |
| mix | audio + speech（两者均 Audio） | audio | 确认共同时间轴，不允许负延迟裁头或配音超长被截断 |
| export | subtitle | subtitle | 复用 SRT / VTT / LRC 导出 |

图允许分支、合流、重复能力，不允许循环或给一个输入端口绑定多个来源。缺少输入、类型或语言矛盾直接报错；不自动补节点、不回退全流程。只检查图内节点使用的引擎和连接。未使用的素材槽可以暂时不绑定。

素材槽声明类型，运行时的 `bindings` 才包含具体路径。语言未知的字幕需要确认；字幕与音频一起使用需明确对应，检查时间轴。提交时冻结素材身份，执行前重新核验，素材变化会要求重新提交。只有目标字幕和一个 TTS 节点时，不执行或预检分离、ASR、翻译。

## 模板和现有任务

`GET /api/v1/pipeline/graph-capabilities` 返回七项能力及串行执行/不支持部分续跑说明，不初始化模型。V2 模板复用现有 `PresetCatalogService` 和 `/api/v1/pipeline/presets`；通过 `include_graph=true` 获取同目录的 V1/V2 条目。旧客户端默认只看到 V1。创建、复制、修订冲突与内置只读规则沿用原服务。

模板保存图、节点参数、素材槽和明确产出，不保存具体素材绑定、凭据、运行快照或画布坐标。连接使用引用，翻译凭据仅保留在任务服务私有内存；声音使用已有不可变配方快照。正式编辑页使用同一目录的创建、复制及修订接口，保存后可以回到工作台选中该流水线。

目录保留原有六个 V1 预设，另提供四个明确连线的 V2 常用模板。旧预设通过 `GET /api/v1/pipeline/presets/{id}/graph-draft` 显式转换为编辑草稿；每个旧输入独立保留为槽，不根据步骤顺序猜连线。用户检查后另存，原预设不变。参数表单按节点读取真实能力元数据，不因浏览页面探测模型就绪或开始执行。

`POST /api/v1/pipeline-runs` 接受 V1 或 V2，V2 仍沿用原任务队列、状态与产物索引。返回产物保留 `node_id` / `port`，不会按能力名称覆盖同类型实例。旧 V1 默认版本、显式 `model: null`、历史读取和阶段恢复继续保留。

V2 暂不支持节点级缓存、部分续跑、失效传播或自动重跑。重启后中断的图任务保留历史，并明确不能续跑；显式重试会重新执行整个图。结果未知的远程请求仍需按原规则核对，不自动重试。

## 明确分组的图批次

`POST /api/v1/batch-runs` 的 V2 请求使用共同的 `execution_profile: {version: 2, graph}` 和 `groups: [{group_id, label, bindings}]`，不混用 V1 的 `inputs`。组 ID 唯一且稳定；相同主文件可以属于不同绑定组合，不按路径静默去重。V1 请求与历史记录仍保留原契约。

所有组的图、语言、对应关系和素材身份先通过校验，才创建持久化批次并启动既有监控器。共同声音及翻译配置在接纳时冻结，不提前注册一批可执行的 pending 任务来绕过批次并行限制。每组通过原任务服务创建普通 DAG 子任务，节点/任务输出目录和产物索引继续隔离。

`client_request_id` 标识一次提交；相同标识与相同请求返回已接纳批次，标识复用于不同内容会报错。它不表示自动重试执行。响应保留 `current_task_id`、历史 `task_ids` 和组内状态，并提供重试可用性/阻止原因。浏览器迟到响应不能替换后来的编辑草稿或把旧错误串入另一组。

失败重试复用冻结配置；已完成组不重复执行。输入身份改变、远端结果未知或没有原冻结上下文时要求用户重新核对，不能从最新设置恢复一个“相同”任务。普通任务接口不允许直接重试或续跑批次子任务，避免绕过组归属和批次并行限制。私有连接上下文只在进程内保留，不放进公开响应或批次持久化 JSON；重启后的历史图批次不宣称可以续跑。暂停、节点级续跑和缓存均不在本轮范围。

目录发现通过 `media_kind` 区分 `audio`、`subtitle`、`all`，默认保持旧音频发现行为。工作台可扫描字幕文件并形成字幕独立的组。文件名/相邻位置仅提供配对候选，不替代语言与时间轴确认。

## 参数展示与执行缺省

图节点中 Qwen ASR 的未指定设备与精度保持模型加载器的真实缺省，页面显示自动/未指定，不填入看似已生效的 CPU 或 bfloat16。时间戳默认关闭；显式强制对齐器会使时间戳生效，页面应说明该关联。保存和运行不会因为只打开面板就注入一套展示默认值。旧 V1 profile builder 继续保留历史 CPU、bfloat16、对齐器和时间戳默认选择，显式值优先；不会因共享能力描述修正而改变旧任务行为。

引擎声明的 `hotwords` 数组和 `vad_kwargs`、`forced_aligner_kwargs` 对象为合法参数。界面区分未知参数与合法但结构复杂的参数，提供热词列表及按需对象编辑，校验格式后显式保存；取消、切换节点和模板往返不把另一节点的草稿误应用，也不静默删除原值。
