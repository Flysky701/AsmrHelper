# 工作台：选择流水线、绑定素材、运行

工作台用于重复使用已保存的流水线。选择流水线后，添加音频或 SRT/VTT/LRC 字幕，为输入槽明确选择素材，按需调整节点参数，检查条件后点击“运行一次”。选择、保存、复制及编辑参数都不会自动执行任务。

## 选择已保存的流水线

工作台、设置入口和独立“流水线编辑”页面读取同一个预设目录。四个常用节点模板如下；模板中的语言、引擎和声音是可见的初始参数，使用前应按素材调整。

| 模板 | 明确节点 | 产出 |
| --- | --- | --- |
| 音频转字幕 | 语音识别 → 字幕导出 | 字幕文件 |
| 字幕翻译 | 字幕翻译 → 字幕导出 | 译文字幕文件 |
| 目标字幕直接配音 | 语音合成 | 配音音频 |
| 音频翻译配音 | 语音识别 → 字幕翻译 → 语音合成，同时导出译文 | 配音音频、字幕文件 |

工作台只读展示节点和产出。“新建流水线”或“编辑结构…”进入独立编辑页；设置也提供同一入口。节点、连线、素材槽和产出在编辑页定义，允许重复节点和分支。内置模板只读，可另存为自定义；自定义更新校验修订，冲突时保留草稿。保存后返回工作台并选中保存结果。

原有六个步骤预设仍保留，通过“旧版步骤预设”显式转换后在编辑页检查。旧格式没有连线证据，所以每个输入先转换成独立素材槽，不猜测流程；确认后另存，原预设不变。原工作台素材、声音参数和步骤草稿也保留，但旧开关不参与新的图任务执行。

## 素材与前提

添加文件或扫描目录只把素材加入池，不自动绑定。一个槽存在多个候选时自行选择；移除素材后原绑定保留并提示缺失，避免悄悄换文件。一个图只提交一个任务，不把目录里的多个音频自动展开为批量任务；历史批次仍可从任务中心查看。

未使用的槽不增加运行依赖。节点输入可以来自素材槽或图中前序节点的输出；缺失、循环、类型矛盾和语言不匹配会阻止提交，不自动补前序或回退到完整流程。

- 直接配音需要非空且具备有效时间轴的目标语言字幕；只检查图中 TTS，不检查或执行分离、ASR、翻译。
- 语言未知时先核对并明确确认；已有不同语言证据不能用确认勾选冒充目标语言。异语字幕需用户选择带翻译节点的流水线或补充目标文本。
- 字幕与音频共同校准或混音时需确认对应同一录音，后端核验时间轴范围。不会静默裁掉超长配音或通过负延迟裁头。
- 翻译节点需明确连接和模型。使用当前默认连接的按钮会把实际引用填入当前节点，不假设连接已就绪。

提交时冻结素材身份，执行前再次核验。文件变化需重新检查并提交。素材齐全、检查通过、任务完成分别显示；条件通过不等于执行完成。

## 本次参数与声音预设

每个节点独立调整真实引擎支持的参数，同类节点互不覆盖。调整默认只用于本次运行。点击“保存参数到此预设”才更新自定义预设；内置预设需“另存流水线”。素材绑定和输出目录不写入模板。

TTS 节点可以引用已保存的声音高级预设，或明确复制其声音来源、支持的参数和默认演绎到当前节点。复制不改变原声音预设或节点目标语言；不兼容的引擎、连接、语言、参考素材会明确报错。高级参数与试听共用后端验证及映射，详见[声音与音色指南](voice-lab-v2.md)。

## 编辑草稿、运行与结果

离开未保存的编辑草稿会提示确认；取消返回保留工作台素材和本次参数。切换流水线前会提示放弃尚未保存的本次参数。编辑草稿、绑定和参数可以本地恢复，格式无法识别的数据保留待恢复，不直接删除。

“检查执行条件”只检查实际图内节点需要的素材、模型和连接。“运行一次”先检查再提交；等待提交响应时阻止导航及重复点击。成功后任务中心明确选中新任务；也可从最近任务主动回看历史记录。任务错误归属和原有结果入口保持不变。

每个节点保存独立产物，图定义决定最终交付内容。V2 暂不提供节点级缓存或部分续跑；中断后显式重试会重跑整个图。远程结果未知时沿用核对机制，不自动重试消费服务。

## 模型可用性缓存

运行环境的依赖导入与 CUDA 检查结果保存到项目 `.cache/runtime-probes/`，成功结果跨启动复用，不再每五分钟或每次启动自动重新导入依赖。文件存在性等轻量检查仍执行。缓存不包含凭据，也不表示模型已完成真实推理。

成功、明确缺少依赖和未能确认的结果分别保存。FunASR / Qwen3-ASR 的模块导入使用 45 秒总上限，其他环境模块及 CUDA 检查仍为 30 秒；不按模块数量无限延长。超时保持“状态未知”，显示当前模块和耗时，真实导入异常明确显示异常类型。ASR 未确认结果最多缓存 5 分钟，到期后下次查询重试；提示会明确标为历史缓存及上次检测时间，也可点击“验证”立即重试。旧版 ASR 失败缓存重新核验一次，旧成功缓存仍可复用；不会把超时当作缺依赖或可用。这些检查仅导入依赖，不代表实际 ASR 推理通过。

安装或修复依赖完成、点击模型“验证”会清除对应环境缓存；解释器、依赖目录/安装元数据、主要环境变量及 CUDA 驱动文件变化会使缓存失效。同一进程内并发请求同一环境共享检测结果。普通页面刷新复用仍有效的缓存。手工修改深层依赖文件或硬件状态变化未被文件签名识别时，请点击“验证”强制重新检查。

缓存损坏时重新检测；无法写入缓存时继续本次检测并保留进程内结果。缓存可删除后重建，不影响模型、配置、素材与历史任务。

重新扫描可刷新原有队列的字幕发现结果。执行结果中的 `companion_subtitle` 记录检测结果和未采用原因；原字幕文件保持不变。

带伴随字幕的旧阶段检查点会因字幕检查策略升级而失效，避免恢复过去未经语言检查的对齐结果；无伴随字幕任务的历史恢复指纹保持不变。已有正式语音检查点失效时仍沿用现有保护机制，要求另建任务，避免恢复时自动重复生成或计费。

## 版本与验证边界

以上为当前源码行为，[节点工作流 V2](workflow-graph-v2.md) 记录接口和限制。本阶段仅隔离构建及 mock 验证，未替换本机 dist/exe 或重启应用；运行版需另行受控刷新。真实模型、桌面缩放/指针和最终视觉仍待用户验收。
